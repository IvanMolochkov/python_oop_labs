## Описание интерфейсов

### `Calculate` (interfaces.py)
Обязывает классы (`Pitcher()` и `Defensive()`) реализовать метод `calculate()`

### `Printable` (interfaces.py)
Обязывает классы (`Pitcher()` и `Defensive()`) реализовать метод `to_string()`

---

## Реализация в классах

### `Pitcher(Player, Calculate, Printable)`
- `calculate()` — возвращает среднее значение `ERA`, `WHIP` и `K/9`
- `to_string()` — возвращает строку с именем, командой и результатом `calculate()`

### `Defensive(Player, Calculate, Printable)`
- `calculate()` — возвращает сумму `PO` и `A` (Total Chances)
- `to_string()` — возвращает строку с позицией, именем, командой и результатом `calculate()`

Оба класса реализуют оба интерфейса одновременно — это множественная реализация интерфейсов.
