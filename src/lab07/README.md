# Лабораторная работа №7
*Консольное приложение*

## Цель работы
- Объединить все знания из ЛР1–ЛР6 в единое работающее приложение
- Реализовать интерактивный CLI-интерфейс с меню и вводом пользователя
- Применить разбиение на слои: CLI, бизнес-логика, хранилище
- Реализовать сохранение и загрузку данных через JSON
- Закрепить типизацию, собственные исключения и паттерн Стратегия

---

## Структура проекта

```
lab07/
├── main.py        # Точка входа — запускает CLI
├── cli.py         # Интерфейс: меню, ввод, вывод. Никакой бизнес-логики
├── app.py         # Бизнес-логика: все операции над коллекцией
├── storage.py     # Сохранение и загрузка данных в JSON
├── exceptions.py  # Собственные исключения предметной области
└── players.json   # Файл с данными (создаётся автоматически)
```

### Назначение файлов

**`main.py`** — единственная точка входа. Создаёт `CLI` и запускает главный цикл.

**`cli.py`** — только ввод и вывод. Принимает данные от пользователя, передаёт в `app.py`, форматирует и выводит результат. Не обращается к коллекции напрямую.

**`app.py`** — вся бизнес-логика. CRUD, фильтрация, сортировка, подсчёт статистики. Все методы аннотированы типами и имеют docstring.

**`storage.py`** — сериализация объектов в JSON и десериализация обратно. Вызывается автоматически при старте и выходе.

**`exceptions.py`** — собственные исключения: `PlayerNotFoundError`, `DuplicatePlayerError`, `InvalidPlayerTypeError`, `StorageError`.

## Описание CLI

### Пункты меню

| Пункт | Действие |
|---|---|
| 1 | Показать всех игроков (форматированная таблица) |
| 2 | Добавить питчера (ERA, WHIP, K/9) |
| 3 | Добавить защитника (PO, A, DP, позиция) |
| 4 | Найти игрока по имени |
| 5 | Удалить игрока с подтверждением |
| 6 | Фильтрация (по типу, команде, статусу, BA) |
| 7 | Сортировка с выбором стратегии |
| 8 | Статистика коллекции |
| 0 | Выход (с автосохранением) |

### Обработка ошибок ввода

Все поля защищены от некорректного ввода:
- строка вместо числа → сообщение об ошибке, возврат в меню
- дубликат имени → `DuplicatePlayerError`
- игрок не найден → `PlayerNotFoundError`
- некорректные значения атрибутов → `ValueError` из валидаторов ЛР-1

### Подтверждение опасных операций

При удалении игрока запрашивается подтверждение:
```
Удалить "Aaron Judge"? (y/n):
```

### Сохранение и загрузка

- При запуске `python main.py` — автоматически загружаются данные из `players.json`
- При выходе (пункт 0) — данные автоматически сохраняются
- Если файл не существует — коллекция начинается пустой
