## Реализованная коллекция

В рамках лабораторной реализован контейнер для хранения объектов класса `Player`, созданных в ЛР-1.

Контейнерный класс `PlayerList` хранит группу игроков и предоставляет удобный интерфейс для управления ими.

### Структура класса

> `_items` — внутренний список объектов `Player` <br>
> `add(item)` — добавляет игрока в коллекцию <br>
> `remove(item)` — удаляет игрока из коллекции <br>
> `remove_at(index)` — удаляет игрока по индексу <br>
> `get_all()` — возвращает всех игроков <br>
> `find_by_name(name)` — ищет игрока по имени <br>
> `sort_by_name()` — сортирует по имени <br>
> `sort_by_team()` — сортирует по команде <br>
> `sort_by_batting_avg()` — сортирует по batting average (по убыванию) <br>
> `sort(key, reverse)` — универсальная сортировка по любому атрибуту <br>
> `get_active()` — возвращает игроков, которые сейчас играют <br>
> `get_top()` — возвращает игроков с рейтингом `very good` <br>
> `__len__()` — возвращает количество игроков в коллекции <br>
> `__iter__()` — позволяет итерироваться по коллекции через `for` <br>
> `__getitem__(id)` — позволяет обращаться к игроку по индексу через `[]`
