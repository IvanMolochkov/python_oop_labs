## Реализованные функции и стратегии
 
### Стратегии сортировки (`strategies.py`)
 
| Функция | Описание |
|---|---|
| `by_name` | Сортировка по имени игрока |
| `by_batting_avg` | Сортировка по среднему отбиванию |
| `by_age` | Сортировка по возрасту |
| `by_home_runs` | Сортировка по хоум-ранам |
| `by_name_and_age` | Сортировка по имени и возрасту одновременно |
 
### Функции-фильтры (`strategies.py`)
 
| Функция | Описание |
|---|---|
| `is_active` | Только играющие игроки |
| `is_pitcher` | Только питчеры |
| `is_defensive` | Только защитники |
| `is_top_batter` | Только игроки с BA >= 0.300 |
 
### Фабрики функций (`strategies.py`)
 
Фабрика — это функция, которая создаёт и возвращает другую функцию с параметром "зашитым" внутри через замыкание.
 
| Фабрика | Описание |
|---|---|
| `make_batting_filter(min_avg)` | Создаёт фильтр по минимальному batting average |
| `make_home_run_filter(min_hr)` | Создаёт фильтр по минимальному количеству хоум-ранов |
 
### Callable-объекты — паттерн Стратегия (`strategies.py`)
 
| Класс | Описание |
|---|---|
| `InjureStrategy` | Травмирует игрока |
| `RecoverStrategy` | Восстанавливает травмированного игрока |
| `HitHomeRunStrategy` | Добавляет хоум-ран играющему игроку |
 
Callable-объекты реализуют метод `__call__` — их можно передавать как обычные функции и они взаимозаменяемы без изменения кода коллекции.
 
### Новые методы коллекции (`collection.py`)
 
| Метод | Описание |
|---|---|
| `sort_by(key_func)` | Сортировка по функции-стратегии, возвращает новый `PlayerList` |
| `filter_by(predicate)` | Фильтрация по предикату, возвращает новый `PlayerList` |
| `apply(func)` | Применяет функцию ко всем элементам, возвращает новый `PlayerList` |
| `map_to_strings()` | Преобразует игроков в строки через `str()` |
| `make_batting_filter(min_avg)` | Статическая фабрика фильтра по BA |
| `make_home_run_filter(min_hr)` | Статическая фабрика фильтра по HR |
 
Все три метода (`sort_by`, `filter_by`, `apply`) возвращают новый `PlayerList` — это позволяет строить цепочки операций.

## Демонстрация работы
 
### Сортировка (старые методы из ЛР-2)
Сортировка по имени, команде, batting average и произвольному атрибуту через `sort("team", True)`.
 
### `sort_by()` с функцией-стратегией
Сортировка одной коллекции тремя разными стратегиями без изменения кода коллекции:
```python
playoff_player_list.sort_by(by_name)
playoff_player_list.sort_by(by_age)
playoff_player_list.sort_by(by_home_runs, reverse=True)
```
 
### `filter_by()` и фабрики функций
Фильтрация по типу игрока, статусу, и через фабрики с параметрами. Показано сравнение lambda и фабрики — результат одинаковый:
```
lambda:  ['Aaron Judge', 'Gerrit Cole']
фабрика: ['Aaron Judge', 'Gerrit Cole']
```
 
### Цепочка `filter_by → sort_by → apply`
Каждый шаг с выводом и вся цепочка в одну строку:
```python
result = (playoff_player_list
    .filter_by(lambda e: e.status == "yes")
    .sort_by(lambda p: p.batting_avg, reverse=True)
    .apply(add_home_run))
```
Вывод:
```
HR до: [360, 11, 87]
HR после: [361, 12, 88]
 
Aaron Judge: 0.331, 362 HR
Jeremy Pena: 0.195, 89 HR
Gerrit Cole: 0.280, 13 HR
```
