#### @property (геттер) - позволяет обращаться к методу как к атрибуту, без скобок. Используется для чтения закрытых полей
![](/media/lab01/геттеры.png)

![](/media/lab01/сеттеры.png)
#### @classmethod — метод, принадлежащий самому классу, а не конкретному объекту. Принимает cls вместо self, доступен без создания экземпляра
![](/media/lab01/class-metod.png)
#### магические методы:
![](/media/lab01/магические_методы.png)
#### 1. __str__ — определяет, что выведет print(). Для человека, читабельно
#### 2. __repr__ — определяет техническое представление объекта. Для разработчика, точно и однозначно
#### 3. __eq__ — определяет, что значит «равны» два объекта при сравнении через ==
